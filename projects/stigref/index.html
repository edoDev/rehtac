stigref

Fast static STIG and control reference: search, deep links, copy/paste. No account, no backend, no assessment workflow.

Live on original Pages Basic components failing Catalog April 2026
Open live app Backlog Source repo
The published SPA is not copied into this repo. The built library is ~117 MB and ~19,700 files (19,403 per-rule JSON objects). Folding that tree into Rehtac would recreate the Pages-space problem this lab exists to solve. Source of truth for the app remains edoDev/stigref.

What it is supposed to do

Answer “what does this STIG rule say, and how do I link or paste it?” Intune / GPO package tags, KEV browser, product hubs, and the Library Observatory (/insights) shipped on the original site.

Known failures (why this is not “done”)

  • User-reported: several basic components fail in daily use. Treat the old “all backlog items done” status as stale.
  • Empty HTML shell without JavaScript. Deep links depend on the Svelte router after load.
  • NIST 800-53 is a stub. CCI / control counts in the live catalog are 0.
  • Only 5 of 19,403 rules carry a CVE; KEV↔STIG overlap is 0. Threat panels look empty on most rules.
  • Search and rule detail fetch thousands of individual JSON files from GitHub Pages. That is slow and flakes.
  • Vite base is hard-coded to /stigref/, so this app cannot sit at /rehtac/projects/stigref/ without a rebuild.
  • Library is still April 2026. Next DISA ZIP import is still a manual maintainer step.
